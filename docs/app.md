# **APP**

## **Current Status**

Mani is currently in beta and is not yet available in the App Store.

The website should present Mani as an upcoming product and encourage visitors to join the beta.

## **Website Direction**

Show only the chat experience.

Do not present features that are still in development.

Do not create screens or user flows that do not exist.

The goal is to build anticipation while accurately representing the current product.
